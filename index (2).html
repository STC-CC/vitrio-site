Questions fréquentes

Dois-je fournir les textes et les photos ?

Vous pouvez les fournir, ou je vous aide à les rédiger à partir de quelques informations sur votre activité. Pour les photos, les vôtres donnent toujours le meilleur résultat.

Que se passe-t-il si je veux arrêter ?

Après les 12 mois d'engagement, vous pouvez arrêter quand vous voulez. Votre nom de domaine et votre contenu vous appartiennent, vous pouvez les récupérer.

Mon site apparaîtra-t-il sur Google ?

Oui, il est préparé pour être trouvé par Google. Comptez quelques semaines pour qu'il apparaisse dans les résultats.

Et si j'ai besoin d'une modification urgente ?

Écrivez-moi : les modifications comprises dans votre formule sont traitées en priorité, les autres sont facturées 30 €.
